Open the app and install it Where your data lives

Installing it

  • Android / Chrome / Edge — open the app, then use the browser menu's Install app or Add to Home screen.
  • iPhone / iPad, Safari — the Share button, then Add to Home Screen.
  • Desktop — the install icon at the right-hand end of the address bar.

It opens in its own window afterwards, with no address bar and its own icon, and starts from whatever page it was installed on.

How the offline part works

A service worker caches the app the first time you load it. After that the page comes out of the cache, so it opens with the connection off entirely — on a plane, at a site with no signal, or on a phone that has run out of data.

The strategy is network-first for the page itself: when you are online it fetches the current version, so a new release is picked up on the next visit, and it falls back to the cached copy the moment the network is not there. Everything else is served from the cache first for speed.

Running it from a file

The app is also a single self-contained HTML file. Download it, put it on a USB stick or in a shared folder, and open it by double-clicking — no web server, no install, no internet. Browsers refuse to register a service worker or read a manifest from a file:// path, so there is no install prompt in that mode, but the app itself works.

PDF export needs two libraries that are loaded on demand to keep the first visit small. Keep the lib/ folder next to the HTML file and they load from there. If you want a genuinely single file with nothing beside it, build one with node build.js --single, which inlines everything.

Moving data between devices

The app is per browser and per device by design — there is no account syncing anything in the background. To move your work:

  • Backup file — export a JSON file holding every business, customer, product and document, then import it on the other device.
  • Google Drive — back up to and restore from a single file in your own Drive. The app only ever sees files it created there, never the rest of your Drive.
  • CSV — customers, products and documents export separately for a spreadsheet or another system.
  • Save folder — on browsers that support it, pick a folder once and exported PDFs go straight into it instead of the downloads pile.

If the app ever opens empty, nothing is necessarily lost. Restore from this device in Settings sweeps the browser's storage for any copy of the database left behind by an older build or a half-finished import, and offers it back with a summary of what is in it.

Updating

There is nothing to update by hand. Load the app while online and the newest version replaces the cached one; your data is untouched by that, because it is stored separately from the app itself.
